# Сетевые проверки боя

Исторические результаты старых реализаций удалены: они не подтверждают текущую
версию кода. Последняя переработка автоматического огня агентом не собиралась
и в сетевой сессии не проверялась. Сборку выполняет пользователь;
тестирование начинается только после отдельного разрешения.

## Приёмка после разрешения

Dedicated server и два клиента; отдельные тестовые GameMode/карта.
Не переключать основные defaults ради smoke-теста.

- ASC owner = PlayerState, Avatar = текущий Pawn на сервере и owning client.
- Нет повторной выдачи grants при possession/OnRep_PlayerState.
- Серверный выстрел расходует один патрон, попадание применяет damage GE.
- У обоих клиентов согласованы здоровье, экипировка и смерть; смерть запускает GA_Death через Dead state.
- Повторная активация и переэкипировка не обходят fire cooldown.
- После respawn старые Pawn, попадания в труп и callbacks не меняют новую жизнь.
- Release, UI, reload, смена оружия, смерть и потеря ADS прекращают очередь.
- Проверить initial replication, late join и возврат UI после respawn.
- Инвентарь: первый перенос из коробки после холодного старта Editor, пустая/занятая ячейка, stack/swap, смерть во время drag.

Runner `Tools/Testing/Run-NGCombatSmoke.ps1` и `NGCombatTestGameMode` — вспомогательные
средства. Перед запуском сверить их сценарий с текущей экипировкой и ассетами;
наличие runner не доказывает покрытие актуального оружейного контура.

Параметры задержки, потерь, нагрузки и допустимые отклонения согласовать до прогона.
Отчёт выполненного теста должен указывать версию кода, конфигурацию и фактический результат.
