# Архитектура runtime модулей

`NEXTGENONE` использует два независимых runtime модуля. Ответственность и решения по каждому модулю описаны рядом с его `Build.cs`.

- [GameplayFoundation](../../Source/GameplayFoundation/ARCHITECTURE.md) — GAS, ввод и ядро инвентаря.
- [UIModule](../../Source/UIModule/ARCHITECTURE.md) — UI, HFSM и представление данных.
- [NEXTGENONE](../../Source/NEXTGENONE/ARCHITECTURE.md) — игровые правила и интеграция систем.
